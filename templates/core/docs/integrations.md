# Integrations

Mocca cares about responsibilities, not brands. Choose tools only when they
improve a project responsibility.

| Responsibility | Chef's Recommendation | Bootstrap behavior |
| --- | --- | --- |
| Agent harness | Codex | Documented, not installed |
| Engineering discipline | Ponytail | Use when available |
| Codebase intelligence | Graphify | Initialize after meaningful code exists |
| Spec-driven workflow | GitHub Spec Kit | Initialize when a non-trivial spec begins |
| Repository context | GitHub MCP | Opt-in |
| Current library documentation | Context7 | Opt-in |

Use deterministic checks for deterministic questions. Replace a recommended
tool only when another implementation meets the same responsibility better.
